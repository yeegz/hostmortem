# Code of conduct

Hostmortem follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep
technical disagreements about the code and the evidence. Harassment,
personal attacks and discriminatory language are not acceptable in issues,
pull requests or any other project space.

To report a problem privately, use GitHub's "Report a vulnerability" form on
this repository (it reaches the maintainer only) and say it is a conduct
report. Reports are handled confidentially.
